# NIZAM — Project Walkthrough

> **NIZAM** is an open-source, API-first, multi-tenant communications control platform built on **Laravel 12** and **FreeSWITCH**. It provides programmable telephony routing, call flow execution, real-time event streaming, and a modular extension system.

## Architecture Overview

```
┌─────────────────────────────────────────────┐
│  API Layer (Controllers, Requests, Routes)  │  ← Validation, auth, rate limiting
├─────────────────────────────────────────────┤
│  Service Layer (PolicyEvaluator, Compiler)  │  ← Business logic, orchestration
├─────────────────────────────────────────────┤
│  Model Layer (Eloquent, Policies, Events)   │  ← Data access, authorization, auditing
├─────────────────────────────────────────────┤
│  Infrastructure (DB, Redis, Queue, ESL)     │  ← Persistence, caching, async processing
└─────────────────────────────────────────────┘
```

### Core Principles (Non-Negotiables)
1. **Database is source of truth** — all state lives in the database, FreeSWITCH config is derived
2. **Dialplan is a compiled artifact** — generated by `DialplanCompiler`, never hand-authored
3. **API-first always** — every operation goes through REST API
4. **No business logic in UI** — UI is a thin client consuming the API
5. **Multi-tenant by default** — every resource is tenant-scoped
6. **Event-driven state tracking** — immutable event records, webhooks, SSE streams

## Key Domain Models

### Telephony Core
- **Tenant** — Multi-tenant root entity (domain-based isolation, quotas, settings, codec policies)
- **Extension** — SIP endpoints with passwords, voicemail PINs, caller ID
- **Did** — Inbound phone numbers with polymorphic destination routing
- **RingGroup** — Simultaneous + sequential ring strategies
- **Ivr** — Interactive Voice Response with digit-to-destination mapping
- **TimeCondition** — Time-based routing (wday, time-of-day, mday, mon)
- **Gateway** — SIP trunk connections
- **Bridge** — SIP bridge configurations

### Call Management
- **CallSession** — Active call tracking with UUID correlation
- **CallDetailRecord** — CDR storage with enhanced fields (codec, quality metrics)
- **CallEventLog** — Persistent event replay log
- **CallTraceEvent** — Per-call trace events
- **CallDeliveryAttempt** — Call delivery tracking (mobile push, PSTN)
- **Recording** — Call recording with metadata and file indexing

### Queue / Contact Center
- **Agent** — Contact center agents with state management
- **Queue** — Call queues with strategy, timeout, wrapup settings
- **QueueEntry** — Individual queue entries
- **QueueMetric** — Real-time and historical metrics

### Routing & Flows
- **CallRoutingPolicy** — Policy-driven routing with condition evaluation
- **Flow** / **FlowVersion** / **FlowNode** / **FlowEdge** — Programmable call flow graph
- **FlowCompiledArtifact** — Compiled dialplan artifacts from flows
- **Schedule** / **ScheduleRule** / **ScheduleBreak** / **ScheduleException** — Business hours
- **HolidayCalendar** / **Holiday** — Holiday-aware routing

### Infrastructure
- **EndpointBinding** — Mobile device registrations with push notification support
- **DeviceProfile** — SIP phone provisioning profiles
- **Webhook** / **WebhookDeliveryAttempt** — Outbound event notifications
- **AuditLog** — Mutation tracking (old/new values)
- **Permission** — Granular permission system
- **SipProfile** / **SslSetting** / **BlockedDestination** — Platform security

## Key Services

### [DialplanCompiler.php](file:///d:/Development/laragon/NIZAM/app/Services/DialplanCompiler.php) (34.5KB)
The heart of NIZAM. Compiles database state (DIDs, extensions, flows, policies) into FreeSWITCH XML dialplan. Flow: **API → Database → Compiler → XML → FreeSWITCH**.

### [EventProcessor.php](file:///d:/Development/laragon/NIZAM/app/Services/EventProcessor.php) (36.6KB)
Processes FreeSWITCH ESL events (CHANNEL_CREATE, CHANNEL_ANSWER, CHANNEL_HANGUP, etc.). Normalizes events, resolves tenants, creates CDRs, dispatches webhooks.

### [PolicyEvaluator.php](file:///d:/Development/laragon/NIZAM/app/Services/PolicyEvaluator.php) (6KB)
Runtime evaluation of call routing policies. Evaluates conditions (time, caller ID, geo prefix) with AND logic.

### [WallboardProjectionService.php](file:///d:/Development/laragon/NIZAM/app/Services/WallboardProjectionService.php) (10.2KB)
Real-time wallboard projections for queue and agent state monitoring.

### [EslConnectionManager.php](file:///d:/Development/laragon/NIZAM/app/Services/EslConnectionManager.php) (7.2KB)
Manages ESL connections to FreeSWITCH with auto-reconnect and exponential backoff.

## Module System

NIZAM uses **nwidart/laravel-modules** with a custom [NizamModule](file:///d:/Development/laragon/NIZAM/app/Modules/Contracts/NizamModule.php) interface providing telecom-specific hooks:

```php
interface NizamModule {
    public function dialplanContributions(string $tenantDomain, string $destination): array;
    public function subscribedEvents(): array;
    public function handleEvent(string $eventType, array $data): void;
    public function permissions(): array;
    public function migrationsPath(): ?string;
    public function routesFile(): ?string;
    public function policyHooks(): array;
}
```

## API Surface

All routes are prefixed with `/api/v1/` and use Sanctum bearer token authentication.

### Route Groups

| Group | Key Endpoints |
|-------|--------------|
| **Auth** | `POST /auth/register`, `POST /auth/login`, `POST /auth/logout`, `GET /auth/me` |
| **Tokens** | `GET/POST/DELETE /auth/tokens` |
| **Tenants** | Full CRUD + settings, provision, stats |
| **Admin** | Dashboard, SSL, SIP profiles, blocked destinations, logs, SIP status |
| **Tenant-Scoped** | Extensions, DIDs, Ring Groups, IVRs, Time Conditions, Gateways, Bridges, Queues, Agents, Flows, Recordings, CDRs, Webhooks, Teams, Schedules, Holiday Calendars |
| **Call Control** | Originate, status, hangup, transfer, hold, recording toggle |
| **Real-time** | SSE event stream, wallboard, agent states, registration status |
| **Analytics** | CDR summary/volume/quality/destinations, codec metrics, queue metrics |
| **Audit** | Read-only audit log access |

### Middleware Stack
- `auth:sanctum` — Bearer token authentication
- `throttle:api` — 60 req/min per user
- `throttle:5,1` — 5 req/min on auth endpoints
- `tenant.access` — Tenant isolation enforcement

## Routing Architecture

NIZAM supports progressive routing complexity:

```
DID → destination                     (basic)
DID → time_condition → destination    (time-aware)
DID → call_routing_policy → outcome   (policy-driven)
DID → flow → graph execution          (programmable)
```

### Flow Runtime Modes
- **Interpreted** — PHP-based `FlowExecutionService` (legacy, being deprecated)
- **Compiled** — FreeSWITCH dialplan + Lua helpers (target mode)

Configurable globally via `FLOW_RUNTIME_MODE` env var, overridable per-flow or per-tenant.

## v1.0 Known Limitations
- Single FreeSWITCH node only (no clustering)
- WebRTC requires external TLS certificates
- No visual flow builder (API-first only)
- Analytics is rule-based (no ML)
- Emergency calling not supported
