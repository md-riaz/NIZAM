# PLANS

Execution planning index and policy.

## Plan folders
- Active: `exec-plans/active/`
- Completed: `exec-plans/completed/`
- Tech debt tracker: `exec-plans/tech-debt-tracker.md`

## Rules
- New plan starts in `active/`.
- On completion, move to `completed/` with outcome note.
- Capture cross-plan debt in tech-debt tracker.
